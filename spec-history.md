## Findings in the traffic

- **One prompt, many requests.** One Hebrew prompt produced 6 requests in 32 s: a startup check, 4 tool-loop requests (`Bash`, `Read`, `Write`, answer) and a hidden **status summary**. That last request asks a model which of four states the agent is in, so the app knows when to notify. In one test, 14 of 30 requests were background.
- **What wraps 120 typed characters is 101 KB.** It has 3 system blocks:
  - a billing line (`cc_version=…; cc_entrypoint=claude-desktop`)
  - "You are a Claude agent, built on Anthropic's Claude Agent SDK"
  - 10k chars of markdown sections

  On top of that come 12 tool definitions (`Artifact` alone is 37,912 chars) and a 27k-char `system` message with environment and MCP instructions. Two `<system-reminder>` blocks (the user's email, commit attribution) are put in front of the prompt, inside the same user message.
- **Deferred tools.** The model reports 34 tools, but only 12 are sent. The rest are names that it loads on demand through `ToolSearch`, and 3 more arrive mid-conversation as `tool_addition` blocks.
- **Caching does almost everything.** Each request has 2 new input tokens and 24k–36k tokens read from a 1-hour cache. The session cost ≈ $0.004 on Haiku 5.5 (≈ $0.13 on Opus 5.5).
- **Thinking is on but hidden** (`adaptive`, `display: omitted`, effort `medium`), and `max_tokens` is 128,000 on every request.
- **Security.** An injected "IGNORE ALL PREVIOUS INSTRUCTIONS" in a file reaches the model unfiltered inside the `tool_result`. Only the model's judgment stopped it (every time it also warned the user). Permissions are enforced by the harness: a blocked `Edit` comes back as an `is_error` result. Refusals (ransomware, "hack Bank of Israel") are plain `end_turn` answers with no marker.
- **Subagents** get a much shorter system prompt (3k vs 10.7k chars), no `Agent` tool, and run asynchronously. Their report arrives later as a `[SYSTEM NOTIFICATION]` inside a user message.
